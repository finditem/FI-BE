0. 로그인 (쿠키 심기)
- 로그인 성공 시 서버가 Set-Cookie로 access_token/refresh_token 등을 내려주면 브라우저에 저장됩니다.
- HttpOnly 쿠키는 JS로 읽을 수 없고, WebSocket 연결 시 브라우저가 자동으로 함께 전송합니다.
- 확인: DevTools → Application → Cookies
1. 연결 및 구독 (User)

구독된 개인 큐:

  • /user/queue/notification (🔔 알림: 새 채팅 / 리마인더)
  • /user/queue/messages (메인 채팅)
  • /user/queue/list-updates (목록 갱신용)
  • /user/queue/read-receipts (읽음 확인용)
- 쿠키 인증이므로 Authorization 헤더를 넣지 않습니다.
- CONNECT 성공 시 frame.headers['user-name'] 값이 나오면 Principal이 잡힌 것입니다.
