# Operations Overview

운영 문서는 배포 환경과 외부 시스템의 기술 계약을 다룬다. 업무 정책은 이곳에 중복해서 정의하지 않는다.

| 작업 | 문서 |
| --- | --- |
| 환경, 배포, Secret, rollback | [Deployment](deployment.md) |
| 로그와 metric 수집 구조 | [Monitoring](monitoring.md) |
| profile 설정 변경 | [Configuration](../contributing/configuration.md) |
| DB migration | [Persistence](../architecture/persistence.md) |

인증과 시간 처리에 관한 독립된 운영 정책은 이번 이전 범위에서 새로 만들지 않는다. 관련 확정 기준이 확인되면 소유 문서를 정한다.
