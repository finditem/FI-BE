# 통계 초기화와 복구

## 초기화

초기화는 담당자 확인 후 [초기화 SQL](../../scripts/initialize-statistics.sql)로 한 번만 수행합니다. 두 통계 테이블이 모두 비어 있어야 합니다.

1. 모든 인스턴스의 회원 및 게시글 쓰기와 관련 배치를 중지하고 기존 트랜잭션 종료를 기다립니다.
2. [배포 절차](deployment.md#배포-흐름)에 따라 통계 스키마와 코드를 배포합니다.
3. 대상 DB를 확인하고 초기화 SQL을 단일 실행자로 실행합니다.
4. 초기값을 실제 집계 대상 수와 대조하고 통계 API를 확인한 뒤 쓰기를 재개합니다.

애플리케이션은 초기화를 자동 실행하거나 초기화 여부에 따라 업무 쓰기를 차단하지 않습니다. 초기화가 끝날 때까지 쓰기 중지를 유지합니다.

## 실패와 복구

- 초기화가 실패하면 쓰기 중지를 유지하고 담당자와 반영 상태를 확인합니다. 재실행을 위해 기존 통계 데이터를 삭제하거나 덮어쓰지 않습니다.
- 집계를 시작한 뒤 기록 기능이 없는 구버전으로 되돌리면 통계가 누락됩니다. 관련 쓰기를 중지하고 forward fix를 우선합니다.
